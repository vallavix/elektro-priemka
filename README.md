# Электро-приёмка

Чек-лист поквартирного обхода при сдаче электромонтажа в новостройке.
Заходишь в квартиру, отмечаешь что есть и чего нет, идёшь в следующую.
В конце — готовая шахматка в Excel по форме, которую обычно требует начальник.

**Открыть: https://vallavix.github.io/elektro-priemka/**

Работает **без интернета** — в подъезде связи нет, и это не мешает.
Ставится на телефон как обычное приложение, но это веб-страница:
ни App Store, ни Google Play, ни установочных файлов.

---

## Зачем это

На сдаче дома электрик обходит несколько сотен квартир и по каждой проверяет
один и тот же список: щит, выключатели, розетки, коробка под плиту, бра,
светильники и розетки в санузле, КУП, проверка на эффект. Обычно это делается
на распечатке, а вечером переносится в Excel руками.

Приложение убирает второй шаг: отметки сразу складываются в ту же таблицу.

## Как поставить на телефон

**iPhone.** Открыть ссылку **в Safari** (важно — из Chrome или из встроенного
браузера Telegram не сработает) → «Поделиться» → **«На экран Домой»**.

**Android.** Открыть в Chrome → меню «⋮» → **«Установить приложение»**.

Дальше один раз запустить с иконки при интернете — приложение сохранит себя
в память телефона и после этого будет открываться в любом подвале.

## Как проходит обход

**Объект** — процент готовности, полоса этажей и сетка квартир.
У каждой квартиры настоящий номер и её номер на этаже (1…12), потому что
на бумаге считают и так, и так. Цвет кружка: зелёный — готово,
жёлтый — есть замечания, красный — критично, пусто — не проверяли.

**Квартира** — сразу список позиций. Если всё в порядке, одна кнопка
**«Всё в порядке · дальше»** проставляет весь список и открывает следующую
квартиру: на чистых квартирах обход идёт в одно нажатие.

Если что-то не так, у каждой позиции три кнопки:

| | значение | как попадёт в Excel |
|---|---|---|
| **✓** | есть, сделано | зелёная галка |
| **✗** | нет — это замечание | красный крест |
| **—** | не предусмотрено проектом | серый прочерк |

После первой ручной отметки внизу появляется **«Остальные N — в порядке»**,
чтобы не проставлять оставшееся по одному.

Ниже — поле «Что осталось», переключатель **Критично**, фото и примечание.
Свайп влево-вправо листает квартиры. Сохранять ничего не нужно, всё пишется само.

**Замечания** — общий список по всем корпусам с фильтром критичные/обычные
и фотографиями. Тап по строке открывает ту самую квартиру.

## Настройка под свой дом

В **Настройках** задаются:

- название объекта;
- корпуса: этажи с/по, сколько квартир на этаже, номер первой квартиры.
  Номера считаются сквозняком — при 12 квартирах на этаже третий этаж даёт 25–36;
- список позиций проверки — можно переименовать, добавить свои, удалить лишние.

Поле **«группа»** у позиции — это объединяющая шапка в Excel
(например «Санузел, коридор»). Пустое поле — колонка идёт отдельно.

## Что получается в Excel

Отдельный лист на каждый корпус:

```
КОРПУС 1
Этаж │ № кв. │ № на эт. │ Щит эл. │ Выключатели │ … │      Санузел, коридор      │ Что осталось │ Примечание
      │       │          │         │             │   │ Светильники │ КУП │ … │
```

Этаж объединён по вертикали на свои квартиры, ✓ зелёные, ✗ красные, — серые.

Плюс лист **«Замечания»**: корпус, этаж, квартира, критичность, что не выполнено,
текст, примечание и **сами фотографии, встроенные в ячейки** (до трёх на квартиру).

Файл собирается прямо в телефоне, без сервера. Открывается в Excel, Numbers,
Google Таблицах и LibreOffice.

## Работа вдвоём

Общей базы нет — данные лежат в телефоне. Чтобы объединить обход с напарником:

1. Ты жмёшь **Выгрузка → Передать напарнику**, получается файл `.json`.
2. Кидаешь его в любой мессенджер.
3. Напарник открывает **Принять от напарника** и выбирает файл.

Квартиры **сливаются, а не затираются**: чужие проверенные добавятся к твоим,
одинаковые пропустятся. Если одну квартиру проверили оба и по-разному,
приложение покажет обе версии — с галками, текстом и временем — и спросит,
какую оставить. Есть кнопки «везде мои» / «везде его». Фото переезжают вместе
с отметками.

## Где лежат данные

Только в браузере твоего телефона (`localStorage` и `IndexedDB`).
Никакого сервера, аккаунтов и передачи данных на сторону: сайт отдаёт
только сам код приложения.

Обратная сторона — данные не переживут очистку данных браузера или потерю
телефона. Раз в пару дней жми **Выгрузка → Резервная копия** и скидывай
файл себе в мессенджер. Восстановление: **Настройки → Загрузить резервную копию**.

Отметки привязаны к адресу сайта, а не к иконке, — переустановка иконки
или обновление приложения их не трогает.

## Для тех, кто хочет свою копию

Обычная статика без сборки, зависимостей и сервера. Нужен только HTTPS-хостинг:
GitHub Pages, Cloudflare Pages, Netlify — любой.

```bash
git clone https://github.com/vallavix/elektro-priemka.git
cd elektro-priemka
python3 -m http.server 8777
```

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `app.css` | стили, светлая и тёмная темы |
| `app.js` | экраны, логика обхода, слияние, сборка выгрузок |
| `xlsx.js` | самописный генератор `.xlsx` и `.zip`, включая картинки в ячейках |
| `sw.js` | офлайн-кэш. **При правке любого файла поднимай `V = 'shm-vN'`**, иначе телефон отдаст старую версию |
| `manifest.json`, `icon-*.png` | имя и иконка на экране «Домой» |

Внешних библиотек нет вообще: `.xlsx` — это ZIP с XML внутри, и он собирается
руками в `xlsx.js` (ZIP без сжатия + CRC32 + OOXML). Поэтому приложение весит
десятки килобайт и работает офлайн.
